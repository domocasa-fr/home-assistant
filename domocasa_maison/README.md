# Domocasa Maison

Pilotez votre maison depuis l'application Domocasa, sur iPhone et sur Android : lumières,
volets, chauffage et climatisation, alarme. Tout reste chez vous : votre Home Assistant garde la
main, et rien n'est ouvert sur Internet.

Cette app est la passerelle entre Home Assistant et les applications Domocasa :

- elle présente vos appareils pièce par pièce, comme la famille les comprend ;
- elle se jumelle à un téléphone en quelques secondes, par un code ou un QR code, depuis la page
  **Domocasa** de la barre latérale de Home Assistant ;
- elle ne demande aucun mot de passe de Home Assistant ;
- elle est surveillée par Home Assistant et relancée toute seule en cas de problème ;
- ses données sont incluses dans les sauvegardes de Home Assistant.

Le mode d'emploi complet est dans l'onglet **Documentation** de l'app.

Domocasa, domotique et sécurité connectée : https://domocasa.fr
